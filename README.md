# THE WORLD — 20 November 2026

A one-page newspaper front page summing up Friday, 20 November 2026: the first-ever Trump-Xi-Putin summit in Shenzhen, the ICJ genocide ruling on Myanmar, Anthropic's Nasdaq debut, the Kerch Bridge strike, and a wire ticker of the day's other news.

`main.py` is pure Python 3 standard library. It draws the whole page with its own 5x7 bitmap font and a minimal PNG encoder, so the output is byte-identical on every run.

## Run

MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
